# Elluna — intégration HTML/CSS/JavaScript

## Lancer le site
Ouvre `index.html` dans un navigateur. Aucun framework ni installation n'est nécessaire.

## Images à ajouter
Place tes fichiers dans le dossier `assets/` et donne-leur les noms suivants (ou adapte les chemins dans `index.html`) :

- `logo-partenaire-gauche.png`
- `logo-universite.png`
- `logo-telecom-nancy.png`
- `statue.png`
- `mascotte.png`
- `micro.png`
- `camera.png`
- `windows.png`

Les images doivent idéalement être des PNG avec fond transparent pour les illustrations. Le dossier `assets-optional` dans le HTML est une coquille : remplace `assets-optional/windows.png` par `assets/windows.png` si tu utilises ce nom.

## Personnalisation
- `style.css` : dimensions, couleurs, placement et animations flottantes.
- `script.js` : comportement du champ de question.
- Le formulaire est actuellement une démonstration côté navigateur. Pour envoyer réellement les questions à Elluna, il faudra le connecter à l'API ou au backend du projet.
